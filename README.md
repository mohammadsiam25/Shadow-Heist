# Shadow Heist

A 2D top-down stealth game developed using Python and Pygame.

## Technologies Used

- Python
- Pygame
- Classical AI
- A\* Pathfinding
- Finite State Machine (FSM)

## Current Features

- Player movement
- Map and wall system
- Wall collision
- Guard AI
- Guard patrol
- Player detection
- Guard chase behavior
- A\* pathfinding
- Vision system

## How to Run

Install dependencies:

```bash
pip install pygame
```

Run the game:

```bash
python main.py
```
